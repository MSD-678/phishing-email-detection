# Phishing Email Detection Model

A machine learning classification project built using Python and Scikit-learn to classify emails as **Safe** or **Phishing** using TF-IDF feature extraction and Naive Bayes.

## Features
- **Dataset**: Balanced collection of legitimate and phishing email examples.
- **Feature Extraction**: Extracts text and URL indicators via TF-IDF vectorization.
- **Classification**: Classifies emails into Safe and Phishing categories.
- **Model Evaluation**: Displays accuracy score, confusion matrix, and classification report.
